渲染模式
1→2→1：预设第一遍生成界面（狐策/表裏/NC-MAP）→ 界面段藏走 → 卡内嵌（scoped）+ 全局在剩余纯正文上美化（^ 锚定正常、界面不可见）→ 预设第二遍 → 界面按原位拼回。界面与美化正文并存，各管各的。旧模式 = 现状顺序混跑（自动隔离脚本区生效）。切到旧模式自动重算显示。
流式实时渲染
默认关闭（模式一·完整渲染，零影响）。开启后流式期间实时检查下方「段匹配配置」：匹配到起始标签/正则 → 段内容实时交引擎渲染（节流持续更新 + 闭合定格）；匹配到闭合 → 交回酒馆原生通道；流式结束后正式链路渲染整条消息时，正文段区间用流式定格结果拼合（无跳变、不二次渲染正文段）。

第二次预设（阶段③）
阶段③（预设第二遍）总开关，默认关闭：关闭 = 预设正则只跑一次（阶段①），减小前端压力；开启 = 预设正则第二遍再跑一遍（受下方过滤规则 / 「第二次不执行」约束）。
空白段守卫
空白段守卫，默认关闭：开启 = 阶段②/③ 执行脚本时，纯空白段（整段无可见字符）跳过不执行——防「整段匹配型」美化正则（如卡内嵌 ^([\s\S]+)$ 无 \S 守卫）把藏走界面段后残留的孤立换行包成空卡片。默认关闭 = 空卡问题由「清洗规则替换为空 = 删除段」在配置层解决，行为同旧版。
第二次预设过滤
阶段③开启时生效：决定哪些预设正则第二遍再跑一遍。默认「全部」= 全部预设跑一遍。自定义 = 按位置 / 名称过滤（维度之间 OR 任一命中即算匹配；包含 = 匹配到的进第二遍，排除 = 匹配到的不进）。disabled 的脚本始终不参与第二遍。

超时预算（ms）
每条正则最大执行时间，超时跳过（记录 timedOut）。默认 50；范围 1-5000。非法值自动回退 50。
ReDoS 静态预检
执行前检测「嵌套量词」（如 (a+)+）并跳过，防灾难性回溯。关闭则放行被误伤正则（承担卡死风险）。单条误伤可用诊断弹窗「绕过」。

提示词剥离（预设隐藏行为）
开启后每次发送前对整段提示词施加预设隐藏正则（删选项 fox_selc、剥思维链 think 等，按酒馆标准生效）。消息原文 mes 始终完整保存（狐策/玄狐读原文不受影响）。默认开启；关闭则提示词原样发送。
保护替换（rphub 模式）
美化正则替换时把 HTML 文档 / script / style / cot/think / 代码块 / 行内代码 / HTML 标签留原样，只替换普通文本。默认开启。
